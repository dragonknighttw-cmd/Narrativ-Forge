# 📱 Narrativ Forge Mobile

Video Reviewer & Publishing Companion application for Narrativ Forge short-form vertical video pipeline.

## Features

- **Queue Monitor:** Real-time progress monitoring of video rendering steps (Script -> Voiceover -> Scene generation -> FFmpeg assembly).
- **Episode Library:** Browse all 9:16 vertical video episodes, duration, and pipeline statuses.
- **9:16 Vertical Video Reviewer:** Full preview player with Myanmar subtitle overlay, one-tap approval and Google Drive export.
- **Publishing Assistant:** Direct copy of Myanmar titles, descriptions, and hashtags, with native sharing to TikTok, Reels, and YouTube Shorts.

## Quick Start

```bash
cd apps/mobile
npm install
npm run start
```
