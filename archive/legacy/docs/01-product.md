# Product Definition

## Identity
Private, invite-only, standalone Burmese short-form video production system with Manual + Auto modes, human review/approval, and Google Drive export.

## Core principle
Manual creates production data. Auto accelerates the same workflow. Human approves quality. Google Drive stores approved output.

## Output
3-minute target, 9:16, 1080×1920, Burmese, Burmese subtitles. Package: video + subtitles + transcript + script + metadata + thumbnail.

## Workflow
`Idea → Structure → Script → Assets → Processing → Subtitle → Review → Output`

## Strict boundaries
No Logixa Flow, Aether Bridge, public registration/profiles/browsing/comments, direct TikTok/YouTube/Facebook publishing, external downstream delivery, or Google Drive as workflow DB.

App may prepare captions, hashtags, format checks, schedule metadata, manual publishing records, and analytics.

## Final rule
Application DB is source of truth for workflow/version/subtitle/approval/analytics/audit data. Drive is approved-output destination.

## Expanded Auto Mode target
Auto Mode may ingest a full story or story idea, propose an episode plan, generate production assets, optimize hook/SEO/retention/thumbnail/sound choices, support selective revision, prepare cross-platform outputs, and learn from performance data. Every generated plan remains user-reviewable and final export remains approval-gated.
