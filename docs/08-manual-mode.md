# Manual Mode

Manual Mode is the first validation stage of Narrativ Forge. The goal is to validate the content-production loop before relying on automation.

## Manual production stack

| Step | Tool / Method |
|---|---|
| Script | ChatGPT / Claude |
| Voice | Fliki / Edge-TTS |
| Images | Pollinations |
| Video editing | CapCut |
| BGM | Suno |
| Production log | Google Sheets |

## Validation target

Produce **15–20 videos** manually.

During this stage:
- Test **3 hook types**.
- Test **2 subtitle styles**.
- Record production observations and results.
- Check commercial-use/licensing risk for the tools/assets actually used.

## Exit Gate

Manual Mode can exit only when:
- Manual Log exists.
- Hook Library has an initial set.
- Commercial-use risk has been reviewed.

## Feedback into automation

`Manual Data → Hook Library → Auto Defaults → Human Approve`

Manual validation proves the workflow is worth automating; it does not mean automation is complete.
