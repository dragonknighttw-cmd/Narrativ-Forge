# Narrativ Forge — Product Definition

## Identity

Narrativ Forge is a private, invite-only, standalone Burmese short-form video production system with Manual and Auto modes.

Core principle:

> Manual creates production data. Auto accelerates the same workflow. Human approves quality. Google Drive stores approved output.

## Primary output

- Vertical short-form video
- Target duration: 3 minutes
- 9:16
- Target 1080×1920
- Burmese language
- Burmese subtitles
- Package: video, subtitles, transcript, script, metadata, thumbnail

## Audience

- Burmese-speaking viewers
- Psychology / life lessons / motivation
- TikTok / Shorts / Reels audiences

## Business direction

- Brand deals
- Affiliate marketing
- Later AI-assisted production service
- Direct creator revenue is not a core dependency

## Strict boundaries

Not part of the product:

- Logixa Flow integration
- Aether Bridge integration
- Public registration/profiles/browsing/comments
- Direct TikTok/YouTube/Facebook publishing
- External downstream delivery
- Google Drive as workflow database

The app may prepare captions, hashtags, format checks, schedule metadata, manual publishing records, and analytics import/entry.

## Unified workflow

`Idea → Structure → Script → Assets → Processing → Subtitle → Review → Output`

Human approval is mandatory before Google Drive export.

## Final product definition

The application database is the source of truth for workflow state, versions, subtitles, approvals, analytics, and audit data. Google Drive is the approved-output destination.
