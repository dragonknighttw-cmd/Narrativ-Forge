# Narrativ Forge — Manual Mode

Manual Mode is the validation and training-data source for Auto Mode.

## Six-step workflow

1. Idea — 5 min target
2. Script — 30 min target
3. Voice — 15 min target
4. Images — 30 min target
5. Video — 45 min target
6. Publish — 15 min target

## Idea

Capture topic, category, hook, audience, and emotion.

Gate:
- title
- category
- one-line concept

## Script

Use ChatGPT/Claude for a draft, then human-edit it.

Target:
- first 5-second hook
- approximately 3 minutes
- scene breakdown
- cliffhanger/resolution where appropriate

## Voice

Manual options include Fliki and Edge-TTS fallback.

Check:
- duration
- commercial-use status

## Images

Manual workflow uses Pollinations.

Check:
- every scene has an asset
- 9:16
- character consistency

## Video

Manual workflow uses CapCut.

Check:
- duration
- audio sync
- subtitle overlap
- 1080p / 9:16

## Publish

User publishes manually. Record caption/hashtags and production data.

## Manual production log

Track:
`video_id, topic, category, hook, hook_type, script_length, duration, scene_count, tools, subtitle_style, production_time, errors, quality_score, published, platform, views, completion_rate, notes`

## Manual exit gate

- 15–20 videos
- production log populated
- at least 3 hook types tested
- at least 2 subtitle styles tested
- production time measured
- commercial-use risk reviewed
